## Key Ideas

* Every card should have a next-action button
* Read-only dashboards decay into ignored tabs

## Why It Matters

* Display without action creates review debt

## Recommendations

1. Add one primary action per item
2. Wire actions to the real task system

## Transcript

If your dashboard just shows numbers, you built a poster. Put the promote button next to the data. The moment I could turn an idea into a task in one click, I actually started using the thing.
