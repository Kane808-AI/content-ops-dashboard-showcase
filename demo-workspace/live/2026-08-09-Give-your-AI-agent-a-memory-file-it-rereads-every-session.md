## Key Ideas

* A single MEMORY.md index keeps context cheap
* Write-back rules matter more than recall rules

## Why It Matters

* Stateless agents repeat mistakes they already made
* Memory is the difference between a tool and a teammate

## Recommendations

1. Add a memory index to the agent workspace
2. Log decisions, not transcripts

## Transcript

Every session my agent starts by reading one file. That file is its memory. It writes back what it learned before it stops. Sounds boring, but this one habit removed half my repeated corrections.
